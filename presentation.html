Решение

Программируемый комплаенс,
а не обёртка вокруг PDF.

Sandyq встраивает правила комплаенса МФЦА прямо в токен через расширения Solana Token-2022. Блокчейн сам отклоняет несоответствующие переводы.

Без Sandyq

  • Комплаенс проверяется бэкенд API
  • Можно обойти прямым переводом
  • Нет KYC-проверки на блокчейне
  • Любой может получить токены
  • Эмитент несёт ответственность

С Sandyq

  • Комплаенс обеспечивается средой Solana
  • Transfer Hook проверяет каждый перевод
  • KYC-статус хранится на блокчейне (PDA)
  • Счета заморожены до верификации
  • Комплаенс на уровне протокола

Глубокая интеграция Solana

4 расширения Token-2022
работают вместе

Расширение Назначение Почему это важно
TransferHook KYC-проверка при каждом переводе Отправитель и получатель должны иметь is_kyc = true
PermanentDelegate Регуляторный отзыв / заморозка Изъятие по решению суда без согласия держателя
DefaultAccountState Все счета начинают Замороженными Даже счета, созданные через DEX или сторонние программы
MetadataPointer + TokenMetadata Данные об активе хранятся на минте Название объекта, юрисдикция, оценка — на блокчейне

Ключевой момент: Несовместимость с DEX — это не баг, это фича. Ценные бумаги по правилам МФЦА не могут торговаться на нерегулируемых площадках.

Регуляторный контекст

Построено для AIFC STO Framework

Требование МФЦА Решение Token-2022
Только одобренные инвесторы владеют токенами TransferHook — проверяет KYC-список при каждом переводе
Счета верифицированы до получения токенов DefaultAccountState = Frozen — все счета заморожены до KYC
Регулятор может изъять / заморозить активы PermanentDelegate — может перевести токены с любого счёта
Идентификация актива и аудиторский след MetadataPointer — данные об объекте + аттестации на IPFS

Архитектурные решения

Transfer hook read-only. Treasury с is_authority=true. Freeze authority — PDA, не keypair. Несовместимость с DEX намеренная.

Модель безопасности

Fail-closed transfer hook. Счета заморожены по умолчанию. PDA-based authorities. Проверка прав на каждой мутации.

Путь к продакшену

Мультисиг для апгрейда. Формальная верификация хука. Мульти-провайдерная KYC аттестация. SPV в МФЦА.
